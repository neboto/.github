# neboto

Read-only terminal UIs for your cloud. Fuzzy-search everything, open console-style
detail panes, tail logs and chart metrics, and follow links between resources,
all from the terminal. Nothing in them can change your account.

| | Cloud | |
|---|---|---|
| **[neboto](https://github.com/neboto/neboto-tui)** | AWS | `curl -fsSL https://raw.githubusercontent.com/neboto/neboto-tui/main/install.sh \| sh` |
| **[nebaz](https://github.com/neboto/nebaz)** | Azure | `curl -fsSL https://raw.githubusercontent.com/neboto/nebaz/main/install.sh \| sh` |

Both are written in Rust with [ratatui](https://ratatui.rs), MIT-licensed, and share a keymap.

Guide and docs: **[neboto.dev](https://neboto.dev)**
